# Smart Kurashi 商品発見 / 比較サイト調査メモ

## 目的
Smart Kurashi を「日本語のテック/家電ニュース」から、商品発見・比較・レビュー・購入導線を持つサイトへ寄せるための調査メモ。

## 参照した代表的なパターン
- 日本勢: 価格.com / mybest / the360.life / 家電 Watch / ITmedia / GetNavi / GIGAZINE / Impress Watch 系
- グローバル: Wirecutter / Tom's Guide / TechRadar / PCMag / RTINGS / CNET
- AI・ソフトウェア系: Futurepedia / There's An AI For That / Product Hunt / AlternativeTo / G2 風の比較ページ

## 目立った勝ちパターン
1. ファーストビューで「何を選べるサイトか」を一言で明示する。
2. 記事一覧より先に、比較・ランキング・レビュー済み商品を見せる。
3. 商品カードに「向いている人」「注意点」「購入先」をまとめる。
4. 比較ページは価格だけでなく、用途・設置性・維持コスト・家族利用などで並べる。
5. 購入導線は Amazon / 楽天 / Yahoo / 公式 の複数リンクで分岐させる。
6. 1ページ内で「読む → 比べる → 買いに進む」の導線を切らさない。
7. 日本向けでは、賃貸適性・原状回復・工事不要・家族共有・返品条件が信頼形成に効く。

## Smart Kurashi の方向性
- 見出しは「AI・テック」「家電・ガジェット」「商品を探す」「比較・ランキング」に絞る。
- ホームはブログの新着一覧ではなく、商品発見の入口にする。
- レビュー済み商品を先に見せ、その下に比較記事と買い方ガイドを置く。
- 価格や在庫はサイト側で断定せず、販売ページで確認してもらう。

## 現地確認メモ
変更前のライブサイトは、ニュース記事の縦並びが主役で、商品発見サイトとしての即時性が弱かった。
今回の再設計では、トップナビを 4 項目に統一し、ホームの主役を商品・比較・レビューに入れ替えた。
