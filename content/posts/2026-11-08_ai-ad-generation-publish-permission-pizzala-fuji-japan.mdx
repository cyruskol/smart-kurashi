生成AIを広告や映像制作へ導入するとき、多くの組織は最初に「AIを使ってよいか」を決めます。しかし、この一問だけでは足りません。素材を入力してよいこと、画像を変形してよいこと、生成案を採用してよいこと、広告として外部へ配信してよいことは、それぞれ別の権限だからです。

2026年11月、宅配ピザチェーン「ピザーラ」を運営するフォーシーズは、アニメ「Dr.STONE」とのコラボCMについて謝罪しました。TikTokの広告プラットフォームでAIを使った広告の自動生成・配信機能が有効になり、製作委員会の事前監修と許諾を得ていない動画が配信されたと説明しています。問題は、担当者が生成画面で一つの作品を手作業したかどうかだけではありません。許諾済み素材が、自動機能によって別の表現へ変換され、そのまま配信へ進める設定になっていたことです。

同じ時期、フジテレビは湾岸スタジオに設けた「AI Sandbox」で、実写ドラマ制作への生成AI活用を進めていると発表しました。撮影前のイメージ共有、実写、VFX、CG、生成AIを場面ごとに選び、特定の映像制作工程では従来手法より作業工数を最大70〜80％削減できたとしています。ただし、この数字は特定工程の検証結果であり、作品全体の制作費や全工程の平均削減率ではないとも明記しました。

二つの事例は、生成AIに賛成か反対かという単純な対立ではありません。重要なのは、試作できる人と公開できる人、素材を使える範囲と変更できる範囲、効率を測る場所と作品を採用する場所を分けられるかです。日本企業には、AI利用申請を一枚増やすだけでなく、素材から配信停止までをつなぐ「生成・公開権限票」が必要です。

## 結論——生成できる状態と、公開してよい状態を別々に管理します

生成AIを安全に制作へ組み込むには、権限を六つに分けます。

| 権限 | 決めること | 記録する証拠 |
|---|---|---|
| 素材利用 | どの画像、映像、音声、台本を入力できるか | 権利者、契約、用途、媒体、期間 |
| 変換 | 切り抜き、補完、合成、再生成をどこまで許すか | 変更範囲、禁止要素、参照版 |
| 道具利用 | どのAI、広告機能、外部サービスを使えるか | サービス名、機能、学習条件、設定 |
| 採用 | 生成候補のどれを制作物へ入れるか | 確認者、差分、判断理由、未解決点 |
| 配信 | 誰が、どの媒体と対象へ公開できるか | 配信版、対象、期間、承認時刻 |
| 停止・訂正 | 何が起きたら止め、誰が直すか | 停止時刻、影響範囲、修正版、説明 |

「AI利用可」という一つのチェックを六つへ分けると、許諾の飛び越しが見えます。コラボ素材を広告へ使う契約があっても、AIでキャラクターを変形する権限や、自動生成した案を監修なしで配信する権限まで含むとは限りません。社内で試作できても、放送、SNS広告、店頭表示へ公開できるとは限りません。

反対に、全てのAI利用を一律に禁止すると、撮影前の構図確認、危険な事故場面の事前可視化、背景の小さな修正など、管理可能な用途まで失います。生成の入口を閉じるのではなく、権限が変わる境界で止めることが大切です。

## ピザーラの事例は「AI広告」より自動生成と自動配信の接続が焦点です

[ITmedia AI＋の報道](https://www.itmedia.co.jp/aiplus/article/2611/06/2000002937/)によると、フォーシーズはTikTok上でAIを活用した広告の自動生成機能が有効になっていた結果、アニメ製作委員会の事前監修・許諾を得ていない動画を配信したと説明しました。指摘後は、該当動画を含む全てのTikTok広告を停止しています。同社は、広告配信の仕組みや設定状況への理解と確認が不十分だったとしています。

ここで注意したいのは、「担当者が悪意を持って無断生成した」という単純な物語へ縮めないことです。広告プラットフォームには、素材の組み合わせ、サイズ変更、文案作成、対象者別の最適化、生成、配信を連続させる機能があります。運用者が元広告の配信を承認した後、どの範囲まで機械が派生版を作れるかを理解していなければ、承認した版と実際に表示された版が離れます。

通常の広告運用でも、入稿後に複数の見出しや画像を組み合わせる仕組みはあります。生成AIが加わると、既存部品の組み合わせだけでなく、人物、キャラクター、背景、動き、台詞の見え方まで変わり得ます。そのため、従来の「素材は許諾済み」「キャンペーンは承認済み」という管理だけでは、生成された派生表現を覆えません。

企業側は、広告アカウントの設定を単なる技術項目として扱わず、公開権限として管理する必要があります。自動生成を有効にできる人、自動配信を有効にできる人、コラボ素材へ適用できる人を分けます。設定を変えた時刻、変更前後の画面、対象キャンペーン、承認者を残し、媒体側の既定値が変わったときも再確認します。

## 元素材の許諾は、生成された派生版の許諾ではありません

キャラクター、俳優、音楽、写真、台本には、複数の権利と契約条件が重なります。広告での掲載を許された静止画でも、表情を変える、別の台詞を話させる、動かす、他の背景へ合成することまで許されているとは限りません。契約で「デジタル広告」と書かれていても、AI変換、学習への利用、国外配信、個別最適化、二次生成物の保存が明確でない場合があります。

生成・公開権限票では、素材ごとに次を確認します。

- 権利者と許諾窓口を示します。
- 利用できる作品、キャラクター、出演者、音源を特定します。
- 静止画、動画、音声、字幕など、許された形式を分けます。
- 切り抜き、色調整、合成、生成補完、動作生成の可否を分けます。
- 利用できる媒体、地域、対象者、期間を示します。
- 外部AIへの入力、保存、学習、再利用の条件を示します。
- 監修が必要な段階と、監修後に変更してよい範囲を示します。

「全て許可」か「全て禁止」ではなく、変更の種類ごとに可否を決めることが重要です。例えば、比率に合わせた余白補完は許可し、顔や衣装の再生成は不可にできます。字幕の位置変更は担当者確認で進め、台詞の生成は権利者監修へ戻す、といった分岐も作れます。

以前の[AI画像を見た目ではなく撮影・生成・編集の来歴で受け取る記事](https://smart-kurashi.jp/posts/2026-10-24_ai-image-provenance-blue-planet-kanji-c2pa-japan)では、内容、来歴、責任を分けました。今回の権限票は、その来歴を公開判断へつなぐものです。どの素材から作られたかが分かっても、その変更と配信が許されていたかは別に確認しなければなりません。

## フジテレビのAI Sandboxは、試す場所と作品へ入れる判断を分けています

[フジテレビの公式発表](https://www.fujitv.co.jp/company/news/261105.html)は、AI SandboxをAIセンターのもとに置き、ドラマ制作、技術部門、外部のAI関連企業が実際の作品を通じて活用方法を検証すると説明しています。現在放送中のドラマでは、監督が思い描く映像を撮影前に可視化し、実写、従来の映像処理、VFX、AIなどから作品に適した方法を選んでいます。

この形で参考になるのは、AIだけを独立した完成品工場にしていない点です。生成案は、監督の意図を共有する部品にもなり、撮影方法を決める比較材料にもなります。実際の撮影が難しい事故場面では、架空の空撮風景と煙の合成などへ使われていますが、どの手法を採用するかは作品の品質を基準に制作と技術が判断します。

また、最大70〜80％という工数削減値の範囲を限定している点も重要です。これは特定工程の結果であり、作品全体の制作費や全工程の平均ではありません。生成が速くても、権利確認、監修、修正、色調整、音響、納品、公開後対応まで含めれば、全体時間は別に測る必要があります。

[ITmedia NEWSの報道](https://www.itmedia.co.jp/news/article/2611/06/2000002962/)によると、フジテレビは2026年10月期から毎クール一本以上をAI強化枠とし、2027年10月をめどに、制作する全ドラマで作品や場面に応じてAIを活用できる体制を整える方針です。ここでの「全ドラマ」は、全映像をAIで作るという意味ではありません。必要な場面で選択肢として使える組織能力を広げる計画です。

## 試作環境には三つの出口が必要です

AI Sandboxのような実験場を社内へ作る場合、試作を増やすだけでは足りません。候補には三つの出口を用意します。

一つ目は、制作物へ採用する出口です。使用素材、生成条件、手作業の修正、確認者、採用版を固定し、放送や配信の承認へ渡します。

二つ目は、差し戻す出口です。作品の意図、権利、人物表現、技術品質のどこが不足したかを記録し、再生成するのか、従来手法へ戻すのかを決めます。単に「違和感がある」とせず、直す対象を示します。

三つ目は、破棄する出口です。採用しない生成物を、いつ、どこから削除するかを決めます。外部サービス側の保存期間や学習条件も確認します。採用しなかった案が別案件で再利用され、許諾範囲を越えることを防ぎます。

試作は権限を弱く、公開へ近づくほど権限を狭くします。社内だけで見る構図案は制作担当者が作れても、俳優の顔や声を再現した映像は指定環境だけで扱い、放送版への採用は制作責任者、技術、権利担当が確認する、といった段階が必要です。

## 広告プラットフォームの既定値を契約の一部として監視します

自動生成機能は、一度設定すれば終わりではありません。サービス更新で設定名が変わる、新機能が追加される、既存キャンペーンへ推奨設定が提示されることがあります。管理画面で有効になっていることと、社内規程や権利者が許したことは同じではありません。

広告運用では、月次ではなく変更時に次を点検します。

1. 新しい生成機能が追加されたら、既定で有効か無効かを確認します。
2. 元素材からどの要素を生成・変更するかを確認します。
3. 生成案が自動配信されるか、公開前の確認画面を通るかを確認します。
4. アカウント、キャンペーン、広告単位のどこへ設定が効くかを確認します。
5. 外部代理店と自社のどちらが変更できるかを確認します。
6. 設定変更の通知先と、緊急停止できる担当者を確認します。

設定画面のスクリーンショットだけでなく、機能名、説明ページの版、取得日、対象範囲を記録します。表示上は同じスイッチでも、サービス側の仕様変更で動作が変わる可能性があるためです。

中小企業では、制作、入稿、配信、顧客対応を一人が兼務することもあります。担当者を増やせない場合でも、公開前確認を別の人へ依頼する、コラボ案件では自動生成を無効にする、配信上限を小さくする、夜間の自動開始を避けるなど、権限と影響範囲を減らせます。

## 「AI使用表示」だけでは権利と承認を説明できません

生成AIを使ったことを表示する仕組みは、視聴者が制作方法を理解する手掛かりになります。しかし、AI表示が付いているから権利処理が済んでいるとは限りません。逆に、AI表示がないから無断利用だとも断定できません。表示は制作方法の説明であり、許諾と承認は別の証拠です。

公開時には、少なくとも三つを分けます。

- **制作表示**は、生成や大きな編集をどの範囲で使ったかを説明します。
- **権利記録**は、素材と変換について誰からどの条件で許可を得たかを保存します。
- **承認記録**は、最終版を誰がどの媒体へ公開すると決めたかを保存します。

視聴者向けの表示は簡潔で構いませんが、社内記録は具体的である必要があります。問題が起きたとき、「AIを使いました」という一文からは、どの場面を止め、どの版へ戻し、誰へ連絡すべきか分からないからです。

[AI制作物を素材・変更・判断・公開・訂正へ分けた制作証跡の記事](https://smart-kurashi.jp/posts/2026-09-21_ai-creative-production-receipt-qwen-level5-japan)は、公開後に制作工程へ戻る方法を整理しました。今回の生成・公開権限票は、その各工程で「できる人」と「許した人」を分けます。証跡が事実の並びなら、権限票はその事実を変えられる範囲の地図です。

## 日本企業向け「生成・公開権限票」は十二欄で作ります

一案件につき、次の十二欄を一つの識別子へ結びます。

| 欄 | 記録する内容 |
|---|---|
| 案件 | 作品、商品、キャンペーン、媒体、期間 |
| 元素材 | ファイル、版、出所、権利者、取得日 |
| 許諾 | 利用目的、形式、地域、期間、禁止事項 |
| 変換 | 切り抜き、合成、生成、音声化などの範囲 |
| 道具 | AI、モデル、広告機能、設定、外部委託先 |
| 試作権限 | 候補を作れる担当者と環境 |
| 採用権限 | 候補を制作物へ入れられる担当者 |
| 配信権限 | 媒体、対象、予算、開始時刻を確定する担当者 |
| 最終版 | 配信した映像、画像、音声、文案の版 |
| 監視 | 苦情、誤配信、異常生成を受け取る窓口 |
| 停止 | 停止条件、操作権限、代替版、連絡順序 |
| 訂正 | 修正版、説明、権利者連絡、再発防止 |

役職名だけではなく、実際に操作できるアカウントも確認します。「部長が承認者」と規程に書いてあっても、代理店の運用アカウントだけが停止スイッチを持っていれば、夜間の誤配信をすぐ止められません。規程上の権限と技術上の権限を一致させます。

最終版には、ファイルの識別子だけでなく、広告プラットフォームが実際に表示した派生版も含めます。自動最適化を使う場合は、全組み合わせを事前に列挙できないことがあります。その場合は、変更を許す部品、禁止する組み合わせ、監視頻度、一日の配信上限、停止条件を決めます。

## 影響に応じて四段階で公開権限を広げます

生成AIの用途を、次の四段階へ分けます。

### 社内試作

構図、絵コンテ、背景案、撮影方法を社内で比較します。実在人物や契約素材を使う場合は、試作への入力許可を確認します。外部公開は禁止し、保存期間を短くします。

### 限定確認

制作、技術、権利者など、指定した関係者だけで候補を確認します。透かしや案件番号を付け、転送先を制限します。監修コメントと修正履歴を残します。

### 一般公開

最終版、表示、媒体、対象者、期間を確定して公開します。自動生成や自動配信を使う場合は、許された変更範囲、予算、監視、停止担当を有効にします。

### 高影響公開

子ども向け、医療、金融、災害、選挙、著名人の顔や声、強いブランド提携などは、通常広告より厳しくします。法務や権利者の確認、二人以上の公開承認、短い監視間隔、即時停止できる代替版を用意します。

同じ素材でも、社内の構図案と全国配信の広告では影響が違います。段階が上がるたびに、確認者と記録を増やします。逆に、低影響の試作へ本番と同じ重い審査を課して、現場が非公式な道具へ逃げることも避けます。

## 公開後は「見つけた人」から停止操作までを一つの経路にします

誤った広告を最初に見つけるのは、制作担当者とは限りません。視聴者、ファン、権利者、店舗、カスタマーサポートが先に気付くことがあります。通報を受けた窓口が、案件、媒体、配信版、停止担当へすぐ到達できるようにします。

停止手順では、原因調査の完了を待ちません。重大な権利問題や人物表現の誤りが疑われる場合、まず影響を止め、表示済み範囲を保存し、その後で原因を調べます。停止すると証拠が消える仕組みなら、配信画面、設定、時刻、対象、表示回数を保全してから止めます。ただし、証拠保全を理由に配信を長く続けないよう、保存操作を短く定型化します。

代替版も事前に用意します。コラボ広告を止めた後、商品販売まで全て停止する必要があるのか、許諾済みの静止画へ戻せるのかを決めます。止めることと事業を継続することを両立できれば、現場は問題を隠さず早く報告しやすくなります。

訂正時には、「AIが勝手に作った」と説明して終えません。どの設定が有効で、どの承認が欠け、どの範囲へ表示され、何を停止し、どの設定と管理体制を変えたかを説明します。AIは操作主体のように見えても、利用する機能、権限、配信上限を設計する責任は組織に残ります。

## 30日でAI利用申請を公開権限の運用へ変えます

最初の一週間は、現在使っている制作・広告サービスを三つだけ選びます。生成、組み合わせ、補完、音声化、自動配信に関する設定を確認し、誰が変更できるかを一覧にします。コラボ素材、人物、音楽、ブランド資産を扱う案件を優先します。

第二週は、素材利用、変換、道具利用、採用、配信、停止の六権限を分けます。既存契約で明示されていないAI変換は、権利者へ確認するまで限定確認から先へ進めません。代理店や制作会社との役割も、依頼、操作、承認、停止に分けます。

第三週は、実案件を一つ使って訓練します。社内試作から限定確認、一般公開へ進め、途中で無許諾素材、意図しない人物変更、自動配信設定の誤りを一つずつ混ぜます。誰が検出し、どの記録から判断し、何分で停止できるかを測ります。

第四週は、公開後の通報から代替版への復旧までを試します。営業時間外、担当者不在、代理店しか操作できない場合も含めます。停止できなかった権限、連絡が切れた場所、証拠を保存できなかった設定を直し、次回のキャンペーン開始条件へ反映します。

運用開始後は、次の指標を並べます。

- 公開物のうち、元素材と許諾条件へ戻れる割合です。
- 生成・変換された部分を特定できる割合です。
- 最終版と実際の配信版が一致した割合です。
- 公開前に権利者監修を完了した割合です。
- 許可範囲外の派生版が生成または配信された件数です。
- 最初の通報から配信停止までの時間です。
- 停止から許諾済み代替版へ戻るまでの時間です。
- サービスの設定変更から社内再確認までの日数です。

工数削減率だけを成功指標にしません。生成が速くなっても、無許諾配信、監修のやり直し、全広告停止、権利者対応が増えれば、案件全体では速くなっていないからです。
